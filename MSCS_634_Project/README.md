# MSCS 634 Final Project: Advanced Data Mining for Data-Driven Insights and Predictive Modeling

## Dataset
The project uses the UCI Red Wine Quality dataset, containing physicochemical measurements and quality scores for red wine samples.

## Project Steps
1. Data collection, cleaning, and exploration.
2. Feature engineering and regression modeling.
3. Classification, clustering, and association rule mining.
4. Final insights, recommendations, ethical considerations, and presentation materials.

## Major Findings
- Alcohol is positively associated with quality.
- Volatile acidity tends to relate negatively to quality.
- Regression models provide modest score prediction, indicating that sensory wine quality cannot be fully explained by chemistry alone.
- Classification can support practical higher/lower quality screening.
- K-Means clustering identifies groups of wines with different chemical profiles.

## Ethical Considerations
The dataset is limited to red vinho verde wine and should not be generalized to all wines or consumers. Model results should be transparent, validated, and used as decision support rather than as the sole basis for quality or market decisions.
